BuildCycle 建造全周期管控平台
版本说明 / 交付包说明
============================================================

【这个包是什么】

完全自包含的绿色包。客户电脑上不需要装 Python、不需要联网、
不需要管理员权限，解压后双击「启动.bat」即可使用。

【客户只需要做三件事】

  1. 解压到一个文件夹（比如 D:\工程项目管控平台）
  2. 双击「启动.bat」
  3. 等几秒，软件打开

【包内结构】

  启动.bat            客户唯一入口
  一键安装.bat        免安装提示，双击同样能起（兼容旧版说明）
  使用说明.md         给客户看的完整说明，建议打印或转发给客户
  main.py             程序入口（含崩溃兜底：报错会写日志+弹窗，不闪退）
  app\                程序本体
  resources\          样式表、图标
  python\             便携 Python 3.12.10 + 全部依赖（已精简）
  data\               首次启动自动创建，客户的数据都在这里

【版本 / 环境】

  便携运行时    Python 3.12.10 (amd64)
  界面框架      PySide6-Essentials 6.11.2（仅 QtCore / QtGui / QtWidgets）
  数据库        SQLAlchemy 2.0 + SQLite（标准库 sqlite3）
  文档解析      python-docx / openpyxl / PyPDF2
  检索          标准库 sqlite3 关键词检索（无需向量库）
  未压缩体积    约 130 MB
  压缩包体积    约 49 MB


【v0.2.0 更新内容】

  1. AI 聊天：每条消息（AI 的和你的）都有「复制」「删除」按钮。
     删除会同时从 AI 的记忆里移除这条消息，AI 不会再引用它；
     输入框旁新增 🧹 一键清空当前对话。
  2. 聊天内容可选中、可复制；「正在思考」不再卡界面。
  3. 知识库：双击任意知识源/搜索结果，弹窗查看完整分块内容，
     可一键复制全文；所有长内容区域（预览/回答/输入框）都加了滚动条。
  4. 修复重大卡死问题：AI 回复时网络请求改在后台线程执行，
     不再阻塞界面；修复 SQLite 跨线程崩溃与任务对象被回收导致的闪退。

【相对上一版改了什么】

  1. 从「联网安装」改为「自包含绿色包」：客户不再需要装 Python、
     不再需要下载约 400MB 依赖，第一步不再有 90% 的失败点。
  2. 移除 7 个代码零引用的依赖：matplotlib、numpy、requests、
     jieba、bm25s、fastembed、sqlite-vec（全库检索确认零引用）。
  3. 界面只打包 QtCore/QtGui/QtWidgets 三个 Qt 模块，
     剔除 QML、Qt 翻译、设计师工具链、类型存根等运行时用不到的部分。
  4. 内置 VC++ 运行库 DLL，老机器/精简系统上也能直接跑，
     不再需要客户单独安装 VC++ 运行库。
  5. 启动脚本改为优先使用随包运行时，并对「运行环境损坏」给出
     中文可读提示（不再让客户去看 Traceback）。
  6. main.py 增加崩溃兜底：启动失败会弹出中文窗口并写
     data\运行日志.txt，不再无声闪退。
  7. 新增应用图标（窗口 + 任务栏）。

【开发机上的构建与验证脚本】

  全部在 F:\project-gc\_build-buildcycle\ 下：

  pyinstall.bat        静默安装便携 Python 3.12.10 到 py312\
  prune.py             精简 runtime（移动文件到 _pruned_backup，可 --restore）
  smoke.py             深度冒烟测试：19 项，含 CPM/EVM/蒙特卡洛手工验算对比
  make_bats.py         生成 .bat（强制校验 GBK + CRLF + 无 BOM + 块内无括号）
  make_icon.py         生成 resources\app.ico（纯标准库，带抗锯齿）
  build_pkg.py         组装交付包 + 端到端验证 + 打 zip
  cleanroom_test.py    清房测试：解压 zip 后完全模拟客户操作

【验证结论（构建机实测）】

  · 深度冒烟测试 19/19 通过，两种平台各跑一遍：
      - QT_QPA_PLATFORM=offscreen（离屏）
      - 真实 Windows 平台（真实窗口系统）
    覆盖：数据库/知识库/记忆库、docx/xlsx/txt 解析、CPM 关键路径
    （总工期 9 天，与手工验算一致）、EVM 挣值（SV=-10 CV=+10 SPI=0.9
    CPI=1.125，与手工验算一致）、蒙特卡洛 500 次区间合理性、
    资源平衡（超载顺延可验证）、工作流、可插拔模块、Source Matrix、
    离线协同导出、全部 10 个页签渲染、Gantt 自绘、设置对话框、
    文件框与消息框、中文字体度量、data/ 删除自愈。
  · 测试覆盖：冒烟 19 项（真实 CPM/EVM/蒙特卡洛/资源平衡计算，
    与手工验算逐项比对）+ 清房测试 29 项 + 最终验收 4 项，全部通过。
  · 清房测试：把 zip 解压到全新目录，不装 Python、不建 venv、
    不带 data/，直接双击「启动.bat」→ GUI 进程正常拉起来，
    data/ 与数据库自动创建；删掉 data/ 再启动能自愈重建；
    双击「一键安装.bat」自动生成桌面图标并启动；
    把 python/ 改名后给出可读中文提示且窗口不闪退。

【已知限制 / 待办】

  · 桌面快捷方式：由「一键安装.bat」自动创建（指向包内 启动.bat，
    图标用 resources/app.ico）。少数精简版系统若拦截快捷方式创建，
    客户手动右键 启动.bat →「发送到」→「桌面快捷方式」即可，
    说明里已写成第 3 步的兜底提示。
  · 便携运行时首次启动会稍慢（约 10 秒），因为要初始化 130MB 的
    运行时目录，属正常现象。
  · 联网搜索依赖外网；离线环境下 AI 只能查本地知识库（已优雅降级）。
